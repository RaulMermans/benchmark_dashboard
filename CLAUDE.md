# CLAUDE.md — Public Benchmark Dashboard Template

## Project identity

This is an unbranded React/Vite benchmark dashboard template. It demonstrates the interface, data contract, and connector architecture without exposing private company data.

## Product goal

Convert a structured JSON payload from a spreadsheet, database, warehouse, or API into an executive benchmark cockpit with ranking views, market share and growth charts, focus-vs-market comparisons, forecast scenarios, event overlays, profile pages, and insight cards.

## Non-negotiables

- Keep the repo public-safe.
- Do not introduce real company names, real logos, private endpoints, or proprietary metric values.
- Use seeded synthetic demo data for local/public examples.
- Keep the live data connector generic through `VITE_BENCHMARK_API_URL`.
- Do not hardcode URLs, tokens, spreadsheet IDs, deployment IDs, database URLs, or secrets.
- Make minimal, readable changes.

## Data source contract

The app expects:

```json
{ "ok": true, "data": { "interface": [], "events": [], "dictionary": [] } }
```

`data.interface` is the source of truth for the UI. It can be generated by Google Sheets, a database, a warehouse query, a serverless function, or a static JSON export.

## Working rules

- Read `README.md` before making changes.
- For data work, inspect only the schema and a small sample row before loading large files.
- Do not inspect or commit `.env.local`, `node_modules`, `dist`, `.git`, or private tooling folders.
- Run `pnpm demo:data`, `pnpm build`, and `pnpm audit:public` before declaring the repo ready.

## Definition of done

- App builds successfully.
- Synthetic data loads locally.
- Public audit passes.
- README explains how to connect a live spreadsheet/API/database endpoint.
- No secrets or real data are committed.

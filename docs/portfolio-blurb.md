# Benchmark Dashboard Template

A public-safe benchmark dashboard template built with React, Vite, Tailwind CSS, and Recharts. The project demonstrates dashboard UX, benchmark logic, data normalization, mock-data generation, and connector-ready architecture for Google Sheets, databases, warehouses, or API endpoints. All bundled data is synthetic and used exclusively to showcase the interface and system design.

## Portfolio note

The GitHub repository is public. A live demo may be deployed separately on Vercel using mock data only. Private or client-connected deployments should not be linked publicly.

# Screenshot Checklist

Use real screenshots only. Do not add fake screenshots.

## Required Captures

- Dashboard overview.
- Market share / ranking section.
- Battle Arena.
- Company profile.
- Company profile route using `#/company/focus`.
- Legacy company profile route using `#/empresa/focus`.
- Forecast section.
- Data source / health state.
- Mobile or narrow viewport if present.

## Capture Notes

- Use the public 5-year synthetic dataset.
- Confirm Battle Arena and company/player profile views show generated benchmark rows without requiring benchmark rows in JSON.
- Confirm forecasts start after the last actual month (`2025-12-01`) and are labelled as scenario projections.
- Avoid browser UI if the screenshot is for the portfolio case study.
- Confirm no private tabs, local files, credentials, or personal notifications are visible.
- Save final screenshots under a predictable public asset path before linking them from the README.
